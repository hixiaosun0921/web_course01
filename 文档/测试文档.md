## 1. 测试概述

### 1.1 测试目的

验证前后端分离后的两个独立工程（`frontend/`、`backend/`）在真实数据库链路上的功能正确性、接口契约一致性与可独立构建运行能力。

### 1.2 测试对象

| 对象       | 说明                                                                 |
| ---------- | -------------------------------------------------------------------- |
| 后端接口   | `backend/`（Spring Boot 3.5 + MyBatis + PostgreSQL 17，JWT 鉴权、BCrypt 密码） |
| 前端界面   | `frontend/`（Vue 3 + Vite，无 mock；开发时 `/api` 代理到后端）        |
| 数据库     | PostgreSQL 17.6（本机免安装版），7 张表，启动时幂等导入种子数据       |
| 数据       | `教学班模拟.txt`（26 门课程 / 38 个教学班）、`学生信息模拟.txt`（40 名学生） |

> 说明：`原型/选课界面.html` 仅作参考，不在测试范围；原 Node mock（`frontend/mock`、`frontend/server.js`）已随本次重构删除。

### 1.3 测试类型

- 后端接口功能与业务规则测试（含鉴权与错误码）
- 前端浏览器端到端测试（真实前后端链路）
- 构建与启动验证（前后端各自独立构建运行）

## 6. 测试结论

1. **后端接口 19/19、前端端到端 21/21、构建与启动 6/6 全部通过**，接口契约与前端预期完全一致（页面组件零改动接入真实后端）。
2. 前后端已彻底分离：`backend/` 可独立打包运行（jar），`frontend/` 可独立构建部署（dist），通过 HTTP + JSON 与统一响应体交互。
3. 数据持久化由 PostgreSQL 承担（7 张表 + 幂等种子导入），选课/退课/候补/意向单数据在服务重启后保留。
4. 鉴权为 JWT + BCrypt，未登录/凭证失效统一返回 1001。

## 附录：测试执行方式

```bash
# 1) 启动本机数据库（免安装 PostgreSQL 17）
powershell -ExecutionPolicy Bypass -File backend/tools/db.ps1 -Action start

# 2) 启动后端（自动建表 + 导入种子数据）
cd backend && .\mvnw.cmd package
java -jar target/course-select-api-1.0.0.jar

# 3) 后端接口测试（19 项）
node backend/tools/api-smoke-test.mjs

# 4) 启动前端并运行端到端测试（21 项）
cd frontend && npm install && npm run dev     # 另开终端
npm run test:e2e
```

- 种子数据重新生成：`node backend/tools/generate-seed.mjs`（读取仓库根目录两个 txt）
- 数据库管理：`backend/tools/db.ps1`（init / start / stop / status / createdb / psql）
