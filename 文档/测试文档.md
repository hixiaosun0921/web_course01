## 1. 测试概述

### 1.1 测试目的

验证 `frontend/`（Vue 3 + Vite 前端 + mock 接口）在需求文档业务规则下的功能正确性、界面可用性与基本安全性，确认可部署运行。

### 1.2 测试对象

| 对象         | 说明                                                        |
| ------------ | ----------------------------------------------------------- |
| 前端界面     | `frontend/src`（登录页、自主选课页、各类弹窗与周课表）       |
| Mock 接口    | `frontend/mock`（读取教学班/学生 txt，实现 RESTful 接口与业务规则） |
| 部署入口     | `frontend/server.js`（静态托管 + `/api`）                    |
| 数据         | `教学班模拟.txt`（26 门课程 / 38 个教学班）、`学生信息模拟.txt`（40 名学生） |

> 说明：`原型/选课界面.html` 为只读参考，不在本次测试范围；Java 后端与 MySQL 尚未实现，不在本次范围。

### 1.3 测试类型

- 接口功能与业务规则测试（含错误码校验）
- 浏览器端到端测试（真实浏览器操作）
- 安全与健壮性测试
- 构建与部署验证

## 5. 缺陷记录

| 编号 | 来源     | 描述                                                         | 级别 | 状态     |
| ---- | -------- | ------------------------------------------------------------ | ---- | -------- |
| D-01 | E2E 测试 | 默认展开的课程属于非默认类别，导致首屏教学班行不显示         | 中   | 已修复，回归通过 |
| D-02 | 安全测试 | 畸形 URL（如 `/%`）导致 Node 进程崩溃，可被利用制造服务不可用 | 高   | 已修复，本地与服务器回归通过 |
| D-03 | 测试用例 | 接口用例未等待异步完成、候选教学班满员，导致 2 项误报       | 低   | 已修正用例，非产品缺陷 |

**修复说明**

- D-01：加载课程后按"当前类别"展开前两门课程（`frontend/src/store/catalog.js`）。
- D-02：路径解码异常返回 400；请求处理包裹 try/catch；请求体限制 100KB（`frontend/server.js`、`frontend/mock/api.js`）。

## 6. 测试结论

1. 已实现范围内：**接口 20/20、端到端 21/21、安全 6/6 通过**，构建与部署验证通过。
2. mock 数据（26 门课程、38 个教学班、40 名学生）可稳定支撑界面与业务规则演示。
3. 发现的 2 个真实缺陷均已修复并回归；服务器已部署修复版本。
4. 遗留风险：登录为演示级（token=学号、统一密码）、无 HTTPS、mock 状态在内存中（重启重置）、未开放公网端口（安全组待放行）。
